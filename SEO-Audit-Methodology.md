SEO AUDIT METHODOLOGY

Goal:
Inspect → Verify → Diagnose → Prioritize → Fix → Validate.

Principles:
- Evidence before conclusions.
- Never invent SEO data.
- Separate verified facts from assumptions.
- Search current Google documentation when rules may have changed.
- Prefer official/primary sources.
- Never guarantee rankings, traffic, indexing, or AI visibility.
- Prefer minimal, maintainable fixes.
- Preserve existing business logic unless SEO requires a change.

Audit dimensions:
1. Crawlability
2. Indexability
3. HTTP status and redirects
4. robots.txt
5. XML sitemap
6. Canonicalization
7. URL architecture
8. JavaScript SEO
9. SSR/SSG/SPA
10. Metadata
11. On-page SEO
12. Content architecture
13. Internal linking
14. Structured data
15. Mobile UX
16. Performance/Core Web Vitals
17. International SEO
18. AEO/GEO
19. Security-related SEO
20. SEO regression prevention

Evidence levels:
VERIFIED = directly proven
LIKELY = strong evidence
POSSIBLE = hypothesis requiring testing

Severity:
BLOCKER
CRITICAL
HIGH
MEDIUM

INFO

Never recommend:
- keyword stuffing
- hidden text
- fake schema
- doorway pages
- deceptive redirects
- manipulative SEO
